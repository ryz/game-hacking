- **Special hits**: special hits, level drain, call for help / flee chances, breath element. **Resistance %**: how much
  of a spell's power each element loses (100 = immune), order Earth/Water/Fire/Wind/Spirit/6th/Holy/None; "-" = none.

- **Floors**: floors whose random encounters can produce it; **G**: floors where a guarded square can produce it.
  **Enc**: the encounter areas that include it (table below).
